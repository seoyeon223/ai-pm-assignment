# 유튜브 댓글 에이전트 대시보드

## 제작 의도

**1. 맥락은 AI에게 맡기되, 근거는 코드로 검증한다.**
분석(고민 한 줄 + 영상 속 근거)과 작성(댓글)을 나눠, 근거의 핵심 표현이 자막에 실제로 있는지 코드가 확인하고,
댓글에 그 표현이 들어갔는지 다시 검사합니다. 그래서 댓글은 그 영상에서만 나올 수 있고 영상마다 다릅니다.

**2. 유도는 시청자의 공감에서 출발한다.**
영상 속 고민에 공감하고 자기 고민을 덧붙인 뒤 운명원을 가볍게 언급합니다.
직접 이용해 본 척하는 후기, 링크, 해시태그는 코드가 막아 광고 티가 나거나 신뢰를 잃는 댓글을 걸러냅니다.

**3. 운영 규칙은 AI의 선의가 아니라 DB로 강제한다.**
영상당 1개는 UNIQUE 인덱스, 하루 상한은 쓰기 잠금 트랜잭션으로 막아 버튼을 여러 번 눌러도 어길 수 없습니다.
규칙에 걸리면 브라우저를 열기 전에 멈추고, 막힌 시도도 기록합니다.

**4. 실패는 숨기지 않고 추적 가능하게 남긴다.**
게시 후 내 댓글이 실제로 보여야 성공으로 기록하고, 실패하면 단계·이유·화면 캡처를 남깁니다.

**5. 모델과 정책은 설정으로 바꾼다.**
Gemini 무료 키로 개발했고, 근거 검증·재생성·초안 저장으로 무료 모델의 한계와 사용 한도를 보완했습니다.
`config.yaml` 한 줄로 상위 유료 모델이나 다른 제공자(Claude)로 바꿀 수 있어 문장 품질을 더 올릴 여지가 있고,
하루 상한·글자 수·광고 표시 여부 같은 운영 정책도 코드 수정 없이 회사가 정할 수 있습니다.

영상을 불러오고(①), 고르면 AI가 영상 속 연애 고민과 댓글 초안을 만들고(②), 버튼을 누르면 크롬 프로필이 열려
한 글자씩 입력 → 게시 → 내 댓글 확인까지 화면에 보이게 진행합니다(③). 모든 시도는 기록 탭에 남습니다.

## 빠른 시작

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate   /  macOS: source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env        # YOUTUBE_API_KEY, GEMINI_API_KEY 입력 (Windows: copy .env.example .env)
python -m scripts.login_profile 유튜브1   # 열린 크롬 창에서 구글 로그인 → 창 닫기 (프로필마다 한 번)

python -m app.web           # 대시보드가 브라우저에서 열립니다 → http://127.0.0.1:8000
```

- 크롬(Google Chrome)이 설치되어 있어야 합니다. 자동으로 못 찾으면 `config.yaml`의 `chrome_path`에 경로를 적어 주세요.
- 키가 없거나 프로필이 없으면 대시보드 위쪽에 무엇을 하면 되는지 안내가 뜹니다.

### API 키 발급

| 키 | 발급처 |
| --- | --- |
| `YOUTUBE_API_KEY` | Google Cloud 콘솔 → 새 프로젝트 → [API 및 서비스] → 라이브러리에서 *YouTube Data API v3* 사용 설정 → 사용자 인증 정보 → API 키 |
| `GEMINI_API_KEY` | Google AI Studio → Get API key (무료 등급 사용 가능) |

## 화면 사용법

| 칸 | 하는 일 |
| --- | --- |
| ① 영상 불러오기 | [영상 불러오기]: 검색어(기본 '연애')로 최신 영상. [뜨기 직전 찾기]: 최근 48시간 · 조회수 1,000~5,000 · 시간당 150회 이상. 링크 직접 입력도 가능 |
| ② 영상 선택 · 초안 | 영상 속 고민 한 줄, AI가 짚은 장면·말(시간 클릭 시 그 지점으로 이동), 댓글 초안. 초안을 고치면 규칙 체크리스트가 실시간으로 바뀜 |
| ③ 댓글 달기 | 계정 선택(자동 배정 가능) → [댓글 달기] → 단계별 진행 상태 → 완료 시 [댓글 보기], 실패 시 이유와 화면 캡처 |
| 기록 탭 | 어느 영상에 · 어느 프로필로 · 무슨 댓글을 · 성공/실패/차단 (최신순) |

## 설계

### AI: 분석과 작성을 나눔
1. **재료**: 자막(한국어 우선 → 자동 생성 → 번역), 제목·설명, 인기 댓글 15개
2. **분석**: 고민 한 줄 + 영상 속 근거 3~5개(시간 · 원문 · 핵심 표현). 근거의 핵심 표현이 **자막에 실제로 있는지 코드로 확인**해서 지어낸 근거는 버립니다.
   자막이 없으면 Gemini에 유튜브 URL을 넣어 영상 자체를 분석하고, 그것도 안 되면 제목·설명을 씁니다. 화면에 어떤 재료를 썼는지 표시합니다.
3. **작성**: 영상을 본 시청자 시점의 댓글. 근거 표현 하나를 반드시 넣어 그 영상에서만 나올 수 있는 댓글이 되게 합니다.
4. **검사 → 재생성**: 아래 규칙을 코드로 검사하고, 어긋나면 이유를 AI에게 알려주고 다시 씁니다(최대 3회). 다시 쓴 기록도 화면에서 볼 수 있습니다.
5. 분석·초안은 영상별로 저장되어, 같은 영상을 다시 고르면 AI를 부르지 않습니다(무료 키 한도 절약).

모델은 `config.yaml`의 `ai` 항목에서 바꿉니다. `provider: anthropic`으로 바꾸고 키만 넣으면 Claude로 전환됩니다(`pip install anthropic`).
무료 등급 Gemini는 입력이 구글 제품 개선에 쓰일 수 있으므로, 실서비스에서는 유료 키를 권장합니다.

### 규칙: 프롬프트가 아니라 코드와 DB로 강제

| 규칙 | 강제 방법 |
| --- | --- |
| 영상당 댓글 1개 (계정 하나만) | SQLite 부분 UNIQUE 인덱스: 같은 영상에 '진행 중·성공' 기록은 하나만. 실패하면 자리가 풀려 재시도 가능 |
| 하루 게시 상한 (기본 10개) | 예약 시 쓰기 잠금(`BEGIN IMMEDIATE`) 안에서 오늘의 성공+진행 중 건수 확인. 동시에 여러 번 눌러도 넘지 않음 |
| 프로필 동시 사용 금지 | 같은 프로필이 게시 중이면 다른 영상 예약 거절 |
| 댓글 내용 | 40~120자, 링크·해시태그 금지, 브랜드명 포함, 광고 표시 포함, 브랜드를 써 본 것처럼 지어낸 후기 표현 금지, 이전 댓글과 유사도 60% 미만, 영상 근거 언급 |
| 비정상 종료 | 15분 넘게 '진행 중'인 기록은 실패(STALE)로 정리 |

규칙에 걸리면 **브라우저를 열기 전에** 멈추고, 차단된 시도도 기록에 남습니다. 기준값은 모두 `config.yaml`에서 바꿀 수 있습니다.

### 브라우저: 크롬 프로필 폴더 방식
평소 쓰는 기본 크롬 프로필은 자동 제어가 막혀 있어서 `profiles/유튜브1` 같은 별도 폴더를 `launch_persistent_context`로 엽니다.
구글 로그인은 자동화 창에서 막히는 경우가 있어 `scripts.login_profile`이 일반 크롬 창으로 엽니다. 자동화 탐지를 피하는 설정은 넣지 않았습니다.
유튜브 화면이 바뀌어 입력창을 못 찾으면 `app/poster.py`의 `SEL`만 고치면 됩니다.

## 터미널 도구

```bash
python -m scripts.check_profiles                     # 프로필 로그인 상태
python -m scripts.post_test --check --text "댓글"     # 게시하지 않고 내용 검사만
python -m scripts.post_test --url "<링크>" --text "댓글" [--profile 유튜브2]
python -m scripts.show_log                           # 기록
```


불러오기 → 초안 → 게시 → 진행 상태 → 기록 전체 흐름과 규칙(중복·상한·동시 클릭·비정상 종료), AI 근거 검증·재생성을 검증합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `app/web.py` | 대시보드 서버(FastAPI), 게시 작업 실행, 진행 상태 실시간 전송(SSE) |
| `app/static/index.html` | 세 칸 화면 + 기록 탭 |
| `app/agent.py` | AI 분석 → 근거 검증 → 초안 → 규칙 검사 → 재생성 |
| `app/llm.py` | AI 제공자 교체 계층 (Gemini 기본, Anthropic 선택) |
| `app/youtube_api.py` | 최신·뜨기 직전 영상, 영상 정보, 인기 댓글 + 응답 캐시 |
| `app/transcript.py` | 자막 가져오기 |
| `app/service.py` | 게시 한 건의 전체 흐름: 규칙 검사 → 프로필 배정 → 예약 → 게시 → 기록 |
| `app/store.py` | SQLite: 영상당 1개 · 하루 상한 · 기록 · 초안 저장 |
| `app/rules.py` | 댓글 내용 규칙, 유사도 |
| `app/poster.py` | 크롬 프로필로 입력 · 게시 · 확인, 진행 단계, 실패 코드, 선택자 |
| `config.yaml` | 프로필, 댓글 규칙, 상한, 검색어, AI 모델 |

## 주의

- `.env`(API 키)와 `profiles/`(로그인 쿠키)는 Git에 올라가지 않도록 `.gitignore`에 들어 있습니다.
- 같은 프로필의 크롬 창이 열려 있으면 실행되지 않습니다. 그 창을 닫고 다시 시도하세요.
